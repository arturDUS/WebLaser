## 🛠️ Tipps / Tips

- **Auflösung:** Browserfenster auf ~1600 px Breite, dann 1:1 aufnehmen.
- **Ausschnitte:** Für Panels die jeweilige Leiste zuschneiden (Windows: *Snipping Tool* / `Win`+`Shift`+`S`).
- **Einheitlicher Look:** Gleiches Theme/Zoomstufe für alle Bilder.
- **Dateiformat:** PNG (verlustfrei, scharfe UI-Kanten).
- **Optional GIFs:** Für Abläufe (z. B. Foto-Clippen, Box erzeugen) sind kurze animierte GIFs sehr hilfreich — gleiche Namensbasis mit `.gif`.

> Solange ein PNG fehlt, zeigt GitHub den Alt-Text/Platzhalter an — die Doku bleibt trotzdem vollständig lesbar.
